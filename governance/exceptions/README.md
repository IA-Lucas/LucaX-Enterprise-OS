# Excecoes Formais (`EXC`)

## Proposito
Abrigar as autorizacoes temporarias do Soberano para descumprir norma nao-petrea, conforme
[FND-01 §8.3](../../foundation/01-constituicao.md) e
[FND-04 §9](../../foundation/04-governanca.md).

## Escopo
Somente normas **nao-petreas**. Nao admitem excecao: PI-01 a PI-14, LV-02, LV-05, LV-12.

## Responsaveis
| Papel | Responsavel |
|---|---|
| Autoriza | **SOBERANO** — indelegavel |
| Registra e fiscaliza expiracao | DEP-GOV |

## As quatro regras que invalidam uma excecao
1. Nao foi autorizada explicitamente pelo Soberano — silencio nunca autoriza.
2. Nao tem prazo de expiracao.
3. Incide sobre norma petrea.
4. Foi renovada tacitamente, sem novo ato.
